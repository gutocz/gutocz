## About me

I'm a **Computer Science student at UFCG** and a **Full Stack Developer** from Brazil.

I really enjoy programming to solve problems — both my own and other people's.  
I like understanding a real need, thinking through the trade-offs, and building something useful from scratch.

I'm also really into creating my own tools and platforms.  
Some examples are my own **music player**, **movie and series player**, **encrypted note-taking app**, **personal finance platform**, dashboards, APIs and small systems that make everyday tasks simpler.

For me, programming is not just about writing code.  
It's about turning ideas into things that actually work.

## Featured Projects

### MyCriptoNote

A privacy-focused note-taking platform with **Zero-Knowledge architecture**.

- Built with **.NET 8** and **Angular**
- Uses **end-to-end AES-256 encryption**
- Keeps encryption keys on the client side
- Focused on privacy and data ownership

### Personal Finance Platform with AI

A web platform created to help me organize and understand my personal finances.

- Built with **Next.js** and **Node.js**
- Includes dashboards for income, expenses and financial overview
- Supports transaction categorization and spending analysis
- Uses the **Gemini API** to explore AI-powered features
- Allows more humanized interaction through chat-based financial assistance
- Can help with expense predictions, automatic categorization and financial insights

### Personal Media Tools

Personal experiments around music, movies and series platforms.

- Custom media organization
- Playback-focused interfaces
- Personal control over content and experience
- Built mainly as a way to learn, improve and solve my own needs
